# KALORA — Women's Boutique

> Where Elegance Has an Aura ✨

KALORA is a luxury women's boutique e-commerce frontend website designed with an elegant, modern, and editorial fashion aesthetic.

The website provides a complete frontend shopping experience, including product browsing, product details, wishlist, cart, checkout, customer account management, and order tracking.

## ✨ Features

### 🛍️ Shopping
- Browse women's fashion collections
- Product search
- Category filtering
- Product sorting
- Product details
- Colour and size selection
- Quantity selection
- Add to Bag
- Buy Now
- Wishlist
- Recently Viewed
- You May Also Like

### 🛒 Cart & Checkout
- Add and remove products
- Increase or decrease quantity
- Automatic cart total calculation
- Cart item count
- Saved addresses
- Checkout page
- Payment method selection
- Order confirmation

### 👤 Customer Account
- User registration and login
- Profile management
- Saved addresses
- Wishlist
- My Orders
- Order tracking
- Logout

### 📦 Order Tracking
Orders can be viewed through a simple tracking timeline:

**Confirmed → Packed → Shipped → Out for Delivery → Delivered**

### 📱 Responsive Design
KALORA is designed to work across:
- Desktop
- Tablet
- Mobile devices

## 🎨 Design

KALORA follows a luxury editorial design direction using:

- Burgundy
- Black
- Gold
- Warm Ivory

### Typography
- Cormorant Garamond
- Playfair Display
- Montserrat

The interface focuses on elegant typography, spacious layouts, large imagery, subtle animations, and premium interactions.
